## 1. What this stage did

U1.3 converted the V1 idea into a minimal executable structural contract. The implemented model is
`Clinical_Residual_Deep_Sets_Cox`: V0 supplies the clinical risk score, each available non-clinical
modality is encoded as a token, Deep Sets aggregates the unordered token set, and the set output is
added to V0 as a residual.

```text
V0 clinical score eta_c
        +
Deep Sets residual delta_eta({blood, ICD, TMA subset})
        =
fused score eta_f
```

Because PyTorch was absent and dependency installation was outside the authorization, the smoke
implementation uses deterministic NumPy reference weights and seven synthetic rows. It performs no
patient fitting and no outcome-based model selection.

## 2. Network contract validated

1. Blood, ICD, and TMA use separate adapters.
2. Every active token contains modality identity, status, and quality information.
3. A shared `phi` network encodes tokens.
4. Masked mean pooling makes the set representation invariant to input order.
5. A shared `rho` network maps pooled evidence to `delta_eta`.
6. Any subset of the three varying modalities is accepted.
7. If the active token set is empty, `delta_eta` is set to exactly zero.
8. Therefore the fused score equals the V0 clinical score exactly in clinical-only cases.
9. A Breslow-tie Cox partial-likelihood function is finite and invariant to adding a constant to all scores.

Frozen smoke dimensions are 16 token units, 24 phi hidden units, and 16 rho hidden units, for 3,225
reference parameters. This is far below the prespecified complexity ceiling.

## 4. What this means for the paper

The stage establishes the engineering and mathematical foundation for the paper's core story:
additional modalities are not forced into a fixed concatenation model, and the backbone can return
to the clinical anchor exactly when no additional evidence is active.

However, the value decision is not implemented yet. V1 only computes a candidate residual fused
score. It does not decide `FUSE`, `FALLBACK`, `RANK_ONLY`, or `ABSTAIN`; those decisions remain the
future responsibility of the Global Value Router after cross-fitted incremental-value evidence is
available.
