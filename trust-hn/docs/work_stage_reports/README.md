## Snapshot policy / 快照规则

- Do not silently overwrite a completed dated pair; create a new pair for a later checkpoint. / 不得静默覆盖已完成的带日期中英文文档；后续检查点应新建一对文件。
- The English and Chinese versions must preserve the same facts, dates, counts, commands, risks, and gate decisions. / 中英文版本必须保留相同的事实、日期、计数、命令、风险和阶段决策。
- Naming convention: `YYYY-MM-DD_<document_slug>.md` in both language folders. / 命名规则：两个语言目录均使用 `YYYY-MM-DD_<document_slug>.md`。
