## 本阶段干了什么

本阶段没有直接继续堆叠新网络，而是把“换几种网络依次试验”冻结成可审计的顺序方案，避免看到结果后不断换结构、挑最好看的模型。

冻结顺序为：

1. **R1/CARS：** 临床锚定、交叉拟合的模态残差分数堆叠。它是低方差诊断/对照，先判断附加模态是否存在稳定可提取的增量信号。
2. **R2/CCADS：** 临床条件化注意力 Deep Sets。在 V1 基础上加入临床风险上下文，以质量感知注意力替代等权平均池化，并加入有界残差收缩门。
3. **R3/NE-GRME：** 带 NULL 专家的门控残差专家混合。Blood、ICD、TMA 分别形成残差专家，即使模态存在，模型仍可给零残差 NULL expert 较高权重。
4. **R4/CC-RST：** 临床条件化残差 Set Transformer。只有前面结果证明存在值得建模的跨模态交互时，才考虑这一更高复杂度方案。

同时冻结了共同评估规则：继续使用相同的 V0、相同的 5 folds × 5 seeds、相同的复杂度门和安全阈值，不允许结果后放宽阈值或挑选有利 seed/pattern。

## 为什么不直接从更大的网络开始

U2 中 25 个外层折有 10 个选择了 V0 等价的 step 0，说明当前问题可能不只是表达能力不足，也可能是附加模态增量信号弱或估计不稳定。因此先用 R1 的低方差方式判断信号，再逐步增加注意力、专家门控和模态交互，学术上更可解释，也更能区分“没有信号”和“网络结构不合适”。

## 各方案如何依次推进

每一个方案都必须分开执行：

```text
冻结候选方案
→ 结构/可训练 smoke
→ 报告并等待审批
→ development CV
→ 报告并等待审批
→ 决定保留 V0、进入下一候选或冻结通过候选
```

不会在一次运行中把四个模型全部试完后挑最好结果。
