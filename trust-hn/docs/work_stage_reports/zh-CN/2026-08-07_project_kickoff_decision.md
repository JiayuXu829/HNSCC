# 决策 0001：分阶段实施 TRUST-HN

**日期：** 2026-08-07  
**状态：** 已接受

## 决策

项目总实施方案是权威执行规范。工作将在每个科学门槛处停止审查，不会从数据发现直接跳到模型拟合。首个执行区块仅限 Phase 0 和 Phase 1。

## 理由

项目核心结论对终点准确性、患者级拆分、捷径对照和封存评估的依赖高于对模型复杂度的依赖。过早建模会造成结局泄漏风险，并可能使主要方法比较失效。

## 后果

- 三个 Study 保持为相互独立的临床或数据生态场景。
- RADCURE 锁定结局、HANCOCK OOD 结局和 GEO 外部结局不得用于调参。
- 在完成组织学和 index date 审计前，数据集名称及人群声明均为暂定。
- 在形成书面 go/no-go 审查前，不授权进入 Phase 2。
