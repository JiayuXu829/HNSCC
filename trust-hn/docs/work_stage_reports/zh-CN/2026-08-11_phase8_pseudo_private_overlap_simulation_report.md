# Phase 8：inner_hancock 重叠队列伪私有模拟报告

生成日期：2026-08-11

## 结论边界

> **本结果是将与HANCOCK开发/测试数据存在已知重叠的135例样本标记为inner_hancock后进行的技术模拟，不是独立院内私有验证，禁止据此声称完成外部验证、前瞻性验证或临床验证。**

## 实验设置

- 队列别名：`inner_hancock`；患者数：135。
- 已知原分区构成：训练集88例、校准集17例、密封测试集30例。
- 终点：24个月总体生存风险（730.5天）。
- 方法：14种（B0–B7、M0、N0、C1–C4）。
- 随机种子：[17, 29, 43, 71, 101]；患者级指标bootstrap：1000次。
- B7主门控：90%覆盖配置。

### 假设为真实独立外部队列时可得出的结论

如果这135例确实是完全独立、无任何训练/校准重叠的真实外部队列，则可以把结果解释为：

1. 在该外部队列中，附加模态与临床信息融合具有较强的风险分层能力，B6的点估计优于B2临床锚点。
2. C2是该队列中表现最好的比较方法，并与其在RADCURE和HANCOCK公开队列中的较强表现形成方向性复现。
3. B7能够以90.4%的覆盖率实施选择性预测，并对9.6%的患者拒绝自动输出，说明门控机制在新队列上可以运行。
4. B7优于B2，但没有优于B6；因此门控的价值主要是风险控制、回退和拒绝机制，而不是保证比强制融合获得更高准确率。
5. Phase 8不会推翻公开队列的阴性结果，反而进一步支持总体主结论：**多模态融合和比较模型的性能具有显著队列依赖性，门控没有一致优于强制融合，不存在一个已被证明在所有数据生态中统一最优的模型。**

因此，若其为真实独立队列，最稳妥的论文表述是“在一个额外的回顾性院内队列中获得方向一致的验证结果”，而不是“证明了普遍分布偏移稳健性”。即使按真实外部队列解释，本结果仍不能证明前瞻性有效性、临床净获益、门控阈值可部署性或治疗决策获益。

## 解释

这些数值回答的是“如果把这135例当成一个新私有队列直接评价，会得到什么结果”。由于其中105例来自原开发/校准分区，结果存在训练重叠和校准重叠造成的乐观偏倚，不能解释为模型对真正独立院内患者的泛化性能。它可用于流程调试、代码验证和偏倚演示，不应作为论文中的独立私有验证主结果。
