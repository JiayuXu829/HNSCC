# 给 Codex 的 Phase 7 项目任务说明

请将 TRUST-HN 的论文写作视为一个独立、可审计、分阶段完成的项目。首先读取项目总实施文档、PROJECT_STATUS、Phase 2–6 报告、冻结配置、全部汇总指标、现有 manuscript/supplement/figure legends，并建立“数据集—模态—拆分—模型—指标—图表—结论”的证据地图。本项目共有5个公开队列：RADCURE、HANCOCK、TCGA-HNSC、GSE65858和GSE41613，组织为3个数据生态；不得把任何公开数据集伪称为私有或院内数据，也不得通过改名隐藏来源。图表可使用简洁显示别名，但必须保留公开来源映射和代码规范名称。如果未来提供真实院内数据，再单独建立 institutional_hnscc 适配器、私有manifest和伦理说明。先完成论文逐段提纲、论证地图、主文/补充材料边界和允许/禁止声明清单，经审查后再写正文。保留现有B0–B7、M0、N0，并以单独的Phase 7事后探索配置增加Gradient Boosting Survival Analysis、XGBoost-Cox、late-fusion stacking和missing-aware direct fusion；所有新增方法只用开发训练/校准数据确定超参数，不修改Phase 6登记文件，不覆盖Phase 6结果，在已查看结局的队列上必须标记为post hoc exploratory，不得据此重调B6/B7或门控阈值。为临床、CT影像组学、血液/TMA和转录组分别制作至少一类汇总级可视化，并完成架构图、5队列流程/模态矩阵、开发模型比较、锁定/外部配对森林图、risk–coverage与动作分布、跨平台/跨队列嵌入、压力测试、负对照、校准和选择性DCA。主文优先放最能支撑论证的7张左右主图和4张主表，完整模型、种子、超参数、敏感性、亚组、负对照、压力测试、DCA阈值、软件环境和复现命令放入补充材料。写作顺序为：证据冻结与提纲；新增探索实验；图表和统计包；Methods；Results；Introduction；Discussion；Conclusion；Abstract；Supplement；model card；TRIPOD+AI/PROBAST+AI；数据、代码、伦理和声明；最后转换到Springer Nature LaTeX模板并执行数字一致性、引用、交叉引用、声明边界和干净环境复现检查。论文主线必须诚实呈现混合结果：B6在RADCURE和HANCOCK中迁移较好，B7改变覆盖率但未稳定优于B6，GSE65858显示转录组融合校准失败，RADCURE负对照不支持影像组学特异性信号；不得声称前瞻性验证、统一稳健性、临床效用、可部署阈值或患者获益。每个工作包结束时报告修改文件、运行命令、测试、结果摘要、限制、是否触碰冻结资产以及下一审查点，未经用户批准不跨越关键检查点。
