# TRUST-HN 的 PROBAST+AI 自评

**评估日期：** 2026-08-08  
**范围：** 回顾性开发和 Phase 6 验证证据的偏倚风险与适用性自评。  
**判断：** 低关注；存在一定关注；高关注；不适用。

这是保守的项目内部评估，不是独立 PROBAST+AI 审查，也不能证明模型适合临床使用。

| 领域 | 开发证据 | Phase 6验证证据 | 对预期临床用途的适用性 |
|---|---|---|---|

| 预测变量/输入数据 | 存在一定关注 | 高关注 | 高关注 |

## 领域1：研究对象和数据来源

**判断：偏倚风险存在一定关注；临床适用性为高关注。**

优势包括公开队列、冻结角色和人数、哈希队列身份、患者级拆分、Phase 6无结局指导的样本选择，以及严格区分RADCURE锁定、HANCOCK OOD和GEO验证。

关注点包括：全部为回顾性二手数据，具有来源特异的选择和历史治疗路径；模态可用性可能选择不同患者；GSE41613是HPV阴性OSCC而非一般HNSCC；没有前瞻性连续入组、工作流取样或实时失败记录。

## 领域2：预测变量和输入数据

**判断：开发阶段存在一定关注；外部验证和临床适用性为高关注。**

优势包括在访问结局前冻结训练获得的预处理、记录临床/模态转换、对缺失模态明确回退，以及排除标识符和诊断元数据。

关注点包括：不同生态的测量流程存在实质差异；平台偏移下GSE65858明显校准失败；RADCURE原始影像组学未明确优于打乱/随机对照；Phase 5不能充分检测语义性模态错配；部分外部临床表示较弱或为常数，尤其是GSE41613 B2；没有前瞻性检测/扫描质量控制流程。

## 领域3：结局

**判断：存在一定关注。**

总生存较为客观，24个月为预设，结局加载与特征准备分离，并使用考虑删失的指标。但各队列的index date、随访构建和文档不同；回顾性随访可能不完整或异质；全因终点未建模竞争风险；错误预测或拒绝的临床后果尚未前瞻性规定。

## 领域4：分析

**判断：作为模型开发研究存在一定关注；对于验证、效用或部署主张为高关注。**

优势包括预设冻结、一次性授权、5个种子、2,000次患者级配对bootstrap、相同子集B7比较、保留阴性/失败结果，以及Phase 6没有重新调参或切换阈值。

关注点包括：拒绝后事件数有限；B7会选择分析人群；缺少拒绝患者的临床处理路径；重要外部场景校准较差；没有外部再校准；B7决策曲线无一致优势；Phase 5有一项HANCOCK非劣效检查失败；Phase 6未一致优于B6；评价的是分别训练的系统而非一个统一模型；没有前瞻性样本量、影响、可用性或实施研究。

## AI/可靠性特异性考虑

| 主题 | 判断 | 原因 |
|---|---|---|
| 数据泄漏控制 | 低关注 | 无结局预运行、冻结哈希和患者级隔离均已测试。 |
| 超参数/阈值乐观偏倚 | Phase 6为低关注 | 访问结局前冻结，之后未切换。 |
| 数据集偏移 | 高关注 | 表现为GSE65858校准失败和HANCOCK B7覆盖率下降。 |
| 隐藏捷径 | 高关注 | 影像组学对照未明确更差；行置换未被充分识别。 |
| 模态缺失处理 | 存在一定关注 | 开发阶段完全缺失回退有效，但前瞻性失败路径未测试。 |
| 不确定性/动作沟通 | 存在一定关注 | 已实现动作，但阈值和后续措施未临床验证。 |
| 公平性/亚组 | 存在一定关注 | 有老年患者探索性警戒信号；外部亚组效能有限。 |
| 可复现性 | 低至一定关注 | 本地测试、回执和哈希较强；独立复现/公共归档待完成。 |
| 人因 | 高关注 | 无临床医生可用性、覆盖、工作量或自动化偏倚评价。 |
| 临床影响 | 高关注 | 无前瞻性影响或随机评价。 |

## 总体结论

TRUST-HN 作为回顾性计算研究具有较强治理，但对确认性临床性能、临床效用和部署主张，当前证据仍具有**高偏倚风险或高度间接性**。它可以支持透明的回顾性方法学结论，包括阴性结果。要获得低风险、临床适用或部署就绪判断，仍需前瞻性中心特异验证，预设拒绝和缺失模态处理，建立工作流质量控制和再校准规则，并开展影响研究。
