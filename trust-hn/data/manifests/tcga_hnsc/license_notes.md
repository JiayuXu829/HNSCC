# TCGA-HNSC / GDC data-use notes

**Audit date:** 2026-08-07  
**Status:** open-access files only.

- All 520 expression files in this acquisition are marked `open` by GDC and use the STAR-counts workflow for Primary Tumor samples.
- GDC open-data users must not attempt participant re-identification and must acknowledge the dataset/accession and the NIH-designated repository in publications and presentations.
- Controlled-access genomic files were explicitly prohibited and were not downloaded.
- Keep TCGA case identifiers inside governed, Git-ignored data areas; tracked reports contain counts and hashes rather than raw ID lists.
- This file is a provenance note, not legal advice.
